## 🟡 مكتوب لكن لم يُختبر بعد على الجهاز الحقيقي

| الميزة | ما الذي ينقص | كيف يُختبر |
|---|---|---|
| **ملف EXE وبرنامج التثبيت لـ Windows** | ✅ بُني وثُبّت واختُبر تلقائياً على Windows في GitHub Actions. ينقص تجربتك على جهازك | ثبّته وجرّب الأوامر |
| **تطبيق Android (APK)** | ✅ بُني واختُبر على محاكي Android 11 (دخول وإرسال أمر واستلام النتيجة). ينقص تجربتك على هاتف حقيقي | ثبّته واربطه بالكمبيوتر |
| الاتصال الحقيقي بـ Claude و OpenAI | يحتاج مفاتيحك | زر «اختبار» في صفحة النماذج |
| الاتصال الحقيقي بـ Telegram | يحتاج رمز بوتك | زر «اختبار» في مركز Telegram |
| Ollama المحلي | يحتاج تثبيته على جهازك | يظهر في صفحة النماذج تلقائياً عند تشغيله |
| تحويل الرسائل الصوتية إلى نص | يحتاج مفتاح OpenAI | أرسل رسالة صوتية للبوت |
| الميكروفون وقراءة الردود بصوت | يعتمد على المتصفح | Chrome أو Edge أو نافذة تطبيق Windows |
| نافذة تطبيق Windows (بدل المتصفح) | تحتاج WebView2 (موجود في Windows 10/11 المحدث) | إذا لم تتوفر، يفتح البرنامج المتصفح تلقائياً |

## 🚫 لن يُبنى

- تجاوز أنظمة مكافحة الغش أو شروط استخدام الألعاب، أو أي وسيلة اختراق.
- قراءة محادثات Telegram أو حسابات لا تسمح بها المنصات.
- تجاوز صلاحيات Android أو Windows دون موافقتك.
