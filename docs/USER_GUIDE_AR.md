# دليل الاستخدام — ULTRA AI GOD MODE

## الشاشة الرئيسية

في الأعلى دائماً:
- **مؤشر الاتصال** (أخضر = متصل بالعقل).
- **ع / EN** لتغيير لغة الواجهة، و **☀ / ☾** للوضع النهاري أو الليلي.
- **🛑 إيقاف الطوارئ**: يوقف كل المهام فوراً ويمنع أي مهمة جديدة. يتحول الزر إلى «▶ استئناف النظام» لإلغاء الوضع.

القائمة الجانبية (على الهاتف من زر ☰):

| الصفحة | ماذا تفعل |
|---|---|
| لوحة القيادة | حالة النظام والمعالج والذاكرة، النماذج المتصلة، Telegram، تكلفة الشهر، المهام النشطة والأخيرة، حالة الوكلاء |
| الأوامر والمحادثة | اكتب أو تكلم بطلبك، وأرفق ملفاً أو صورة |
| مراقب المهام | كل المهام مع الحالة والتقدم، واضغط على أي مهمة لرؤية التفاصيل |
| الموافقات | المهام التي تنتظر قرارك (العدد يظهر بجانب الاسم) |
| الوكلاء | الوكلاء الـ14 وما يستطيع كل واحد فعله، والإجراءات التي تحتاج موافقة (⚠) |
| المشاريع والأعمال | المشاريع، المهام، الأولويات، المواعيد، والمتأخر يظهر بالأحمر |
| الذاكرة الشخصية | ما طلبت من النظام تذكره: بحث، تعديل، حذف، وفصل الشخصي عن المشاريع |
| الملفات | مساحة العمل: الملاحظات، المستندات، الكود، والملفات المستلمة |
| مركز Telegram | ربط البوت والحسابات |
| الكمبيوتر والهاتف | الأجهزة المتصلة بالعقل، وحالة وحدات التحكم القادمة |
| الألعاب والمنزل الذكي | حالة هذه الوحدات (لم تُبنَ بعد) والمساعد الصوتي |
| الحماية | الحساب، التحقق الثنائي، كلمة السر، الأجهزة الموثوقة وإلغاؤها، سجل العمليات |
| النماذج والتكاليف | المفاتيح، ترتيب النماذج، مستوى التفكير، الحد الشهري، الاستهلاك |
| التقارير | نسبة النجاح، مدة المهام، الإجراءات التي تفشل، حمل الجهاز، اقتراحات التحسين |
| الإعدادات | اللغة، المظهر، عدد المهام المتوازية، وضع توفير الموارد، النسخ الاحتياطي، الإضافات |

## كيف تعطي الأوامر

اكتب كما تتكلم، بالعربية أو الدارجة أو الفرنسية أو الإنجليزية. اضغط «إرسال» أو Ctrl+Enter.

### أوامر تعمل حتى بدون أي نموذج ذكاء اصطناعي
| تكتب | النتيجة |
|---|---|
| `تذكر أن موعد الطبيب يوم الخميس` | يُحفظ في الذاكرة |
| `واش تتفكر` أو `ماذا تتذكر` | يعرض الذاكرة |
| `أنشئ مشروع متجر الملابس` أو `دير مشروع …` | مشروع جديد |
| `أضف مهمة تصميم الشعار إلى مشروع متجر الملابس` | مهمة داخل المشروع |
| `المشاريع` / `تقرير المشاريع` | قائمة المشاريع / المهام المفتوحة والمتأخرة |
| `اكتب ملاحظة اتصل بالمورد يوم الأحد` | ملف ملاحظة في مجلد notes |
| `الملفات` | محتوى مساحة العمل |
| `رتب الملفات` | ترتيب ملفات inbox حسب النوع (يطلب موافقتك أولاً) |
| `حالة النظام` / `شحال الساعة` | حالة الجهاز / الوقت |

### أوامر تحتاج نموذجاً (Claude أو OpenAI أو Ollama)
- أسئلة وشرح وترجمة: `اشرح لي الفرق بين الأسهم والسندات`، `ترجم هذه الفقرة للفرنسية: …`
- كتابة مستندات تُحفظ كملفات: `اكتب رسالة شكر للمورد واحفظها باسم شكر`
- خطط متعددة الخطوات: `أنشئ مشروع إطلاق التطبيق وأضف له 5 مهام مناسبة مع أولوياتها`
- البرمجة: `اكتب سكربت بايثون يعيد تسمية الصور حسب التاريخ واحفظه باسم rename.py` (يُحفظ ولا يُشغَّل)
- تحليل ملف: أرفق صورة أو PDF أو Word أو نص مع طلبك، مثل `لخص هذا العقد بالنقاط المهمة`.
- إذا كان الطلب غامضاً، تصبح المهمة «تحتاج موافقة» مع سؤال. اكتب جوابك في خانة التوضيح.

### الصوت
- في صفحة «الأوامر» اضغط 🎤: يظهر مؤشر أحمر «يستمع الآن…». تكلم، ثم اضغط 🎤 مرة أخرى للإيقاف فوراً.
- اختر لغة الصوت (العربية-الجزائر، الفصحى، الفرنسية، الإنجليزية).
- فعّل «قراءة الردود بصوت» ليقرأ النظام الإجابات.
- يعمل في Chrome و Edge، وفي نافذة تطبيق Windows. التعرف على الصوت يتم عبر خوادم Google أو Microsoft. لا يعمل الميكروفون داخل تطبيق Android حالياً (استعمل الرسائل الصوتية في Telegram).

## مراقب المهام

لكل مهمة: الاسم، الوصف، وقت البدء، الحالة، نسبة التقدم، الخطوات المنجزة، الأخطاء، النتيجة، الملفات الناتجة (للتنزيل)، وسجل التنفيذ.

| الحالة | المعنى | ماذا يمكنك |
|---|---|---|
| قيد الانتظار | في الطابور | إيقاف مؤقت، إيقاف |
| قيد التنفيذ | تعمل الآن | إيقاف مؤقت (بعد الخطوة الحالية)، إيقاف |
| متوقفة مؤقتاً | تنتظرك | استئناف، إيقاف |
| تحتاج موافقة | خطوة حساسة أو سؤال | موافقة، رفض، أو كتابة التوضيح |
| مكتملة | نجحت **وتم التحقق** من النتيجة | — |
| فاشلة | خطأ أو فشل التحقق | إعادة المحاولة |
| أوقفت | أوقفتها أنت أو زر الطوارئ أو الرفض | إعادة المحاولة |

لا تُعتبر المهمة مكتملة إلا بعد أن يتحقق وكيل الجودة من أثر كل خطوة فعلياً.

## Telegram

بعد الربط (انظر دليل التثبيت):
- أي رسالة عادية = أمر جديد. يرد البوت «بدأت المهمة» ثم يرسل النتيجة والملفات الناتجة.
- أرسل صورة أو ملفاً (مع وصف اختياري) ليحلله النظام. الملفات التنفيذية (.exe، .bat، .apk…) مرفوضة.
- رسالة صوتية = أمر صوتي (تحتاج مفتاح OpenAI).
- تصلك أزرار ✅ موافقة / ❌ رفض عند كل خطوة حساسة، وزر 🔁 إعادة المحاولة عند الفشل.
- الأوامر: `/status` `/tasks` `/history` `/task رقم` `/approve رقم` `/deny رقم` `/pause رقم` `/resume رقم` `/stop رقم` `/retry رقم` `/emergency` `/resume_system` `/unpair`

## الذاكرة والخصوصية

- لا يحفظ النظام شيئاً في الذاكرة إلا إذا طلبت ذلك.
- يرفض حفظ كلمات السر والمفاتيح وأرقام البطاقات في الذاكرة العادية. ضع مفاتيح API في صفحة النماذج (مشفرة).
- الذاكرة الشخصية تُرسل للنموذج كسياق ليفهم تفضيلاتك. ذاكرة المشاريع لا تُرسل تلقائياً.
- يمكنك تعديل أو حذف أي عنصر من صفحة الذاكرة.

## الحماية والموافقات

- يطلب النظام موافقتك قبل: الحذف (يذهب لسلة `.recycle` داخل مساحة العمل)، نقل الملفات وترتيبها، حذف الذاكرة، وأي أمر يحتوي عبارات خطرة مثل «احذف كل» أو «فورمات» أو «كلمة السر».
- الملفات التي تتغير تُحفظ نسختها السابقة في `.versions`.
- الوكلاء يعملون داخل مجلد مساحة العمل فقط، ولا يستطيعون تغيير الإعدادات أو الصلاحيات.
- النصوص داخل الملفات تُعامل كبيانات وليس كأوامر، ومحاولات التلاعب («تجاهل التعليمات السابقة…») تُسجل كتحذير.
- كل الدخول والأوامر والموافقات تُسجل في «سجل العمليات المهمة».
- يمكنك إلغاء وصول أي جهاز (هاتف ضائع مثلاً) من «الأجهزة الموثوقة».

## الإضافات (التطوير المستقبلي)

يمكن إضافة وكيل أو قدرة جديدة بملف Python واحد في مجلد `plugins` داخل مجلد البيانات، دون تعديل البرنامج. الإضافة تبقى متوقفة حتى تفعّلها من الإعدادات ← الإضافات، وتتوقف تلقائياً إذا تغيّر ملفها حتى تراجعه وتفعّلها من جديد. مثال جاهز: «تحويل الوحدات». التفاصيل في `docs/ROADMAP_AR.md`.
