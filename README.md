# ULTRA AI GOD MODE

نظام ذكاء اصطناعي شخصي: عقل مركزي واحد يفهم أوامرك بالعربية والدارجة، يخطط وينفذ المهام عبر فريق من الوكلاء، يطلب موافقتك قبل أي عملية حساسة، ويتحقق من النتيجة قبل أن يقول «تمت». تتحكم فيه من:

- **تطبيق Windows** (برنامج تثبيت EXE)
- **تطبيق Android** (APK)
- **بوت Telegram خاص**
- أي متصفح على شبكتك

كلها تتصل بنفس العقل، فتبقى المهام والذاكرة والإعدادات متزامنة.

## تشغيل سريع من الكود

```
pip install -r requirements.txt
python run.py
```

ثم افتح `http://127.0.0.1:8765` وأدخل مفتاح الإعداد الظاهر في النافذة.

## ما يحتاج اشتراكاً أو مفتاحاً

| الميزة | تحتاج |
|---|---|
| الأوامر اليومية، المشاريع، الذاكرة، الملفات، Telegram، لوحة التحكم | لا شيء (مجاني، يعمل بدون إنترنت ما عدا Telegram) |
| الفهم الكامل، الكتابة، البحث، تحليل الصور والملفات | مفتاح Claude أو OpenAI (مدفوع حسب الاستعمال) أو Ollama على جهازك (مجاني) |
| البحث في الإنترنت | مفتاح Claude (حوالي 0.01$ لكل بحث) |
| الرسائل الصوتية في Telegram | مفتاح OpenAI |
| بوت Telegram | حساب Telegram (مجاني) |

## البنية

tests/          الاختبارات
